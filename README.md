# CleanStock

Sistema de Gestão de Estoque de Materiais de Limpeza.

## Sobre o projeto

CleanStock é uma aplicação Full Stack desenvolvida para
gerenciar o estoque de materiais de limpeza de uma instituição.

O sistema permite cadastrar produtos, controlar entradas,
registrar consumo, acompanhar perdas por deterioração,
gerenciar fornecedores e compras e visualizar indicadores
de estoque.

## Objetivo

Desenvolver uma aplicação utilizando tecnologias modernas
do ecossistema JavaScript e TypeScript, aplicando boas
práticas de desenvolvimento Full Stack.

## Funcionalidades previstas

- Cadastro de produtos.

- Gerenciamento de categorias.

- Cadastro de fornecedores.

- Controle de compras.

- Controle de entradas e saídas.

- Registro de consumo e deterioração.

- Histórico de movimentações.

- Dashboard com indicadores.

- Relatórios de estoque e consumo.

- Gerenciamento de usuários.
